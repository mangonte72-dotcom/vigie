# Vigie – prévention des accidents

Application mobile installable (PWA) pour site pétrochimique : alerte SOS, déclarations avec photo,
QR codes des équipements, check-lists permis, droit d'arrêt de travail (STOP, 6 étapes),
formation « Droit d'arrêt de travail » avec quiz, registre des risques.

- Application en ligne : https://mangonte72-dotcom.github.io/vigie/
- Données : Supabase (projet `vigie-superbase1`), connexion par e-mail + mot de passe (mot de passe créé dans Réglages > Mot de passe), code par e-mail en secours ; comptes validés par le service HSE.
- `docs-supabase.sql` : script de création de la base (déjà appliqué).

Réalisé par Tamis AI.
